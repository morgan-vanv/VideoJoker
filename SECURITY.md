# Security

VideoJoker is a hobby bot run by a group of friends, but we still want to hear about security problems.

**Please don't open a public issue for a vulnerability.** Instead, report it privately on GitHub:
**Security** tab → **Report a vulnerability**. Only the maintainers can see it.

Things that count: a way to leak the bot's token, to run commands you shouldn't be able to (e.g. bypassing the
VIP or ban checks), to make the bot ping `@everyone`, or a vulnerable dependency we haven't updated yet.

We'll reply as soon as we can (it's a friends' project, so give us a few days) and credit you in the fix if you'd like.
